Project Title: Dev Board

Description:

Dev Board is a practice project that serves as a task management tool for developers. Built using HTML, Tailwind CSS, and JavaScript, this application allows users to track tasks, deadlines, and project progress in a user-friendly interface.

Key Features:

Task Management: Users can view and manage tasks assigned to various projects.
Deadline Tracking: Each task includes a deadline, helping users stay organized and meet project timelines.
Activity Log: Keeps a record of completed tasks, providing a clear overview of progress.
Technologies Used:

HTML
Tailwind CSS
JavaScript
